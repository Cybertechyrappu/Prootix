# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2024-01-01

### Added

- Initial release
- Minimal Terminal environment
- Kali Minimal environment
- Full Kali Desktop environment
- Terminal emulator with tabs
- Session manager
- Package manager UI
- Repository manager
- File manager
- SSH client
- GitHub Actions CI/CD workflows
- Release automation
- Nightly builds

### Features

- Flutter 3.22+ support
- Material 3 theming
- Riverpod state management
- GoRouter navigation
- JNI native bridge
- PRoot container support
- Multi-ABI builds (arm64, arm, x86_64)
